# Music Theory Learning Lab Dashboard

Responsive static website for the Music Theory Learning Lab.

## Deployment
1. In repository Settings → Pages, select **GitHub Actions** as the deployment source.
2. Push changes to main or run the deployment workflow manually from Actions.
3. GitHub Pages will publish the site at the repository's Pages URL.

## Privacy and progress
- Lesson completion and interactive exercise results are saved in browser local storage.
- This means progress is specific to the browser/device and is not yet cloud-synchronised.
- Use the Progress tab to export a JSON backup.
- Do not commit private learning records, credentials or personal information to this public repository.

The private working repository and public dashboard are intended to remain separate.
